# KDC2 骰子游戏（Farkle）

模拟了 KDC2 中骰子游戏的规则：

- 基本目标：双方轮流掷 6颗骰子，通过选择计分骰子累积分数，先达到目标分数者获胜。
- 基础计分：单个 1 得 100分，单个 5 得 50分。
- 特殊组合：三个相同的数字（三个1得1000分，其余按其点数的100倍计分）、顺子（如1-5得500分）等都有对应分数。
- 风险：如果某次投掷没有产生任何可计分的骰子，则本回合累积的分数全部作废（即“Farkle”或“Bust”）。
- “热骰”规则：如果一次将6颗骰子全部计分，则可以拿回所有骰子继续投掷，累积更多分数。
